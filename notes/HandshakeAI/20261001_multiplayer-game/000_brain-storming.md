# 🟢 Brain Storming   

我认为可以把它收敛成一款 4 人合作探索游戏，核心不放在“解出正确历史”，而放在“这一群人最终会留下怎样的历史”。每轮控制在 5～8 分钟，玩家经历一次探索、获得记忆、讨论并修改历史、进入被历史改变后的世界。这样四个阶段互相咬合，历史不是背景文本，而是下一轮的游戏状态。

| 阶段   | 玩家具体做什么                    | 系统发生什么                            |
| ---- | -------------------------- | --------------------------------- |
| 探索   | 四名玩家进入一片未知区域，各自调查地点、物品、人物  | 每名玩家获得不同记忆片段                      |
| 记忆   | 玩家查看自己的记忆，可以向其他人描述，也可以保留信息 | 系统记录个人记忆与玩家说法                     |
| 改史   | 回到“档案馆”，四人共同编辑一份历史记录       | 每人提出、删除、修改一条历史；最后形成共同版本           |
| 世界变化 | 进入下一片区域                    | 世界根据共同历史生成变化，建筑、NPC、道路、事件甚至文字发生改变 |

关键在于“记忆”不能只是找到一张 lore 卡片。每名玩家应该获得带有来源、视角和可信程度差异的信息。例如玩家 A 在废墟里看到一座雕像，系统给他的记忆是“这里曾经供奉太阳神”；玩家 B 看到同一地点，却得到“这里曾经处决异教徒”；玩家 C 找到一块残碑，上面只剩下一句话；玩家 D 没找到任何证据，却拥有上一轮玩家留下的一条记录。

探索结束后，四个人进入档案馆。这里才发生真正的多人游戏。桌面中央放着当前历史，玩家可以把自己获得的记忆拖进去，提出新的叙述，也可以质疑已有记录。每个人拥有有限的“记忆权”，例如本轮只能修改两处历史，因此必须决定什么值得留下。最终形成一份共同历史。

然后历史立刻产生后果。假如玩家写下“这个文明曾经崇拜太阳神”，下一轮可能出现太阳神庙，NPC 开始使用相关仪式，原本关闭的区域因为祭坛出现而开放。假如玩家写下“太阳神只是后来统治者编造出来的”，世界就可能出现另一套结构。玩家不是在阅读世界观，而是在用上一轮留下的文字制造下一轮世界。

这样每轮都有一个很清楚的玩家决策：

> **我刚才看到什么？我相信什么？我愿意让其他人记住什么？**

最有意思的一点可以放在历史的“不确定性”上。系统不需要保证所有生成内容严格符合某个隐藏标准，反而可以允许记忆之间存在冲突。某条历史被写入共同档案后，后续世界会把它当作“事实”运行；但玩家继续探索时，又可能发现证据表明这段历史存在问题。于是下一轮又获得修改历史的机会。

最终，游戏结束时可以展示一份“你们共同创造的历史”：最初世界发生过什么，中途玩家修改过哪些记录，哪些记忆被抹掉，哪些错误最终变成了世界事实。每支队伍得到的世界都不同。

我认为这样核心循环已经足够小，可以先做最小原型：一张探索地图、4 名玩家、每人 2 条不同记忆、一个共同档案界面、3 个可被历史改变的世界变量。只要这套循环跑通，就已经能验证这个创意最关键的部分。

* 做最小原型
* 设计一轮完整流程
* 确定历史修改规则
