# How to Find Startups Using AI

*Estimated Time to Read: 10 mins*

## Goal

Use AI to quickly identify startups that match Mangusta Capital's investment thesis.

The basic workflow is:

**Define thesis → Set hard filters → Choose sector → Search → Verify evidence**

## How VCs Source Startups

VCs source companies through multiple channels:

* Founder and investor networks
* Cold outreach
* Accelerators
* Scout networks
* Industry communities
* Events and conferences
* Online research and databases

The common principle is simple:

**Don't wait for startups to come to you. Actively search for them.**

## Using AI for Startup Sourcing

AI can speed up the initial search, but its output still needs verification.

Useful tools include ChatGPT, Claude, Perplexity, Gemini, and other research-enabled AI tools.

### Step 1 — Give AI the VC Role

Tell the AI to act as a VC analyst.

The important instructions are:

* Think like a VC analyst
* Be structured and data-driven
* Use recent, credible sources
* Don't guess
* Mark missing information as **Not available**

### Step 2 — Give AI the Investment Thesis

Provide the Mangusta investment thesis and have AI identify the criteria it needs to apply.

### Step 3 — Define the Hard Filters

For this project:

**Location**

* U.S.-based preferred
* Europe/Asia acceptable

**Stage**

* Seed or Series A
* Pre-Seed or Series B only if highly compelling

**Product**

* Vertical AI
* Application-layer AI
* Not a general-purpose AI model

**Sector**

* Fintech
* HR / Recruiting / CRM / SDR

Treat these as the initial screening filters.

### Step 4 — Ask AI to Source Companies

Ask AI to find three startups that satisfy the filters.

For each startup, collect:

| Field       | What to verify            |
| ----------- | ------------------------- |
| Company     | Name                      |
| Website     | Official website          |
| Product     | What it actually does     |
| HQ          | Location                  |
| Stage       | Most recent funding round |
| Sector      | Which target sector       |
| Vertical AI | Why it qualifies          |
| Thesis fit  | Why Mangusta might care   |
| Evidence    | Recent credible sources   |

## The Important Part: Verify, Don't Just Generate

The AI-generated list is only a **starting point**.

For every company, verify:

**Does the company actually exist?**

**Is the latest funding really Seed/A?**

**Is it actually Vertical AI?**

**Does it actually operate in the target sector?**

**Is the company U.S.-based or otherwise within the geographic criteria?**

**Is there evidence that customers are actually using or paying for the product?**

That last question goes beyond the basic exercise, but it is critical for real VC sourcing.

## If AI Finds Nothing

Keep the core thesis intact.

Change the search strategy before changing the thesis:

**Different AI tool → different sector → broader search → loosen optional criteria**

Do not immediately weaken the must-have filters just because the first search produced poor results.

## The Real Sourcing Pipeline

For practical use, think of AI sourcing as:

**Discovery → Screening → Evidence Verification → Customer/Traction Validation → Shortlist**

AI is particularly useful for the first two stages. The later stages require progressively deeper research.
